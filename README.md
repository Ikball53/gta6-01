Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

**SOLMAR HEAT** — a Three.js 3D open-world game set in Solmar City. Rosa's five-part story: steal cars, dodge the Solmar PD, run missions, and bank $50,000 to win — or push all the way to $100,000. Nine vehicle types, traffic, a wanted level from 1 to 5, a police helicopter with a spotlight at wanted 3+, a hospital that refills health, a metro loop, and a north-up minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ — try `?scene=menu`, `?scene=chase`, `?scene=downtown`, or `?scene=mission`.
